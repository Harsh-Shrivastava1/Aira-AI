# Roadmap

Planned future enhancements for AIRA. These features are **not currently implemented**.

## Calendar Integration
- Natural language meeting scheduling via Google Calendar API.
- Agenda summarization for the day.

## Proactive Assistance
- Background cron jobs to notify the user of urgent emails or upcoming meetings via browser notifications.

## Enhanced File Analysis
- Support for parsing image data (OCR) and Excel/CSV structured data interpretation.

## Task Management
- Native To-Do list tracking synchronized with Firestore.

*Note: Code modifications should not be made for roadmap items until architectural approval is granted.*
